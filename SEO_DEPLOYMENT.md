# SEO deployment checklist

## Target URL

`https://mufaddalbatti53.github.io/MLB-Portfolio/`

## After pushing this update

1. Wait for the GitHub Pages workflow to finish.
2. Open `https://mufaddalbatti53.github.io/MLB-Portfolio/` and confirm the page loads normally.
3. Open `https://mufaddalbatti53.github.io/MLB-Portfolio/sitemap.xml` and confirm it contains the canonical homepage.
4. Add a Google Search Console URL-prefix property for `https://mufaddalbatti53.github.io/MLB-Portfolio/`.
5. Verify ownership using the HTML file or HTML meta-tag method Google provides.
6. Submit `sitemap.xml` in Search Console.
7. Use URL Inspection on `https://mufaddalbatti53.github.io/MLB-Portfolio/` and request indexing once after deployment.
8. Add `https://mufaddalbatti53.github.io/MLB-Portfolio/` to the website field on the GitHub profile `mufaddalbatti53`.
9. Add the same portfolio URL to LinkedIn contact info / Featured and Instagram bio if desired.

## Identity targets

The site is intentionally optimized for natural searches such as:

- Mufaddal Battiwala
- Mufaddal Battiwala developer
- Mufaddal Battiwala portfolio
- Mufaddal Battiwala Java developer
- Mufaddal Battiwala Spring Boot
- mufaddalbatti53
- Mufaddal Kolkata developer

Do not add repetitive hidden keywords. Google ignores the legacy meta-keywords tag and can treat keyword stuffing as spam.

## Important expectation

SEO can make the page technically strong and easy to understand, crawl, and index. It cannot guarantee first position for every query, especially a broad first-name-only query such as `Mufaddal`. Exact-name and branded searches are the realistic primary target.

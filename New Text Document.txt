Here are the exact one-line terminal commands to generate your secrets locally, followed by how to configure them in Render.

1. Generate JWT_SECRET and RATE_LIMIT_HMAC_SECRET

Run these two commands in your terminal (Git Bash, macOS Terminal, or Linux) to generate cryptographically secure random keys:
• For JWT_SECRET (64-character hex string):bash
openssl rand -hex 32
Use code with caution.
• For RATE_LIMIT_HMAC_SECRET (32-character hex string):bash
openssl rand -hex 16
Use code with caution.
(If you are on Windows PowerShell without OpenSSL, run this instead: [Convert]::ToHexString((1..32 | ForEach-Object { Get-Random -Maximum 256 })))

2. Generate ADMIN_PASSWORD_HASH (BCrypt)

Because Spring Security expects a BCrypt hash starting with $2a$ or $2b$, you can generate it using either Python (fastest) or a quick Java command.
• Option A: Using Python (1-Liner)
First install bcrypt if you don't have it (pip install bcrypt), then run this command (replace YourStrongPassword123! with your actual chosen password):bash
python -c "import bcrypt; print(bcrypt.hashpw(b'YourStrongPassword123!', bcrypt.gensalt(12)).decode())"
Use code with caution.
• Option B: Using Java / Spring Security (No Python Needed)
Inside your /backend folder (after Maven has downloaded dependencies), run:bash
mvn exec:java -Dexec.mainClass="org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder"
Use code with caution.
Or create a temporary 5-line HashGen.java file, run it, and delete it immediately so your password is never saved in Git:java
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;

public class HashGen {
    public static void main(String[] args) {
        System.out.println(new BCryptPasswordEncoder(12).encode("YourStrongPassword123!"));
    }
}
Use code with caution.

3. How to Add and Use These in Render

1. Open your Render Dashboard: Go to your mlb-portfolio-api Web Service and click Environment in the left sidebar.
2. Add the Key-Value Pairs: Click Add Environment Variable for each secret:
	• ADMIN_USERNAME → Enter your chosen username (e.g., mufaddal_admin).
	• ADMIN_PASSWORD_HASH → Paste the entire BCrypt output starting with $2a$12$... or $2b$12$... (do not add quotes around it in Render's input box).
	• JWT_SECRET → Paste the 64-character string from Step 1.
	• RATE_LIMIT_HMAC_SECRET → Paste the 32-character string from Step 1.
3. Save & Redeploy: Click Save Changes. Render will automatically restart your container with the new variables injected.
4. How You Log In:
	• When visiting https://github.io, type your plain-text password (YourStrongPassword123!), not the hash.
	• Your Spring Boot backend hashes what you typed and compares it against ADMIN_PASSWORD_HASH in memory.

Important Security Rules

• Never commit these values into application.yml, .env files tracked by Git, or chat logs.
• Watch out for $ signs in local .env files: If you test locally using a .env file, wrap the BCrypt hash in single quotes (ADMIN_PASSWORD_HASH='$2b$12$...') so your shell doesn't mistake $2 or $1 for empty environment variables. In Render's web UI, paste it directly without quotes.
